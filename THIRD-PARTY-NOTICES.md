# Third-party notices

Slick is open source under the MIT license, in LICENSE. The app also contains the code and
data below, each under its own license. Each entry names the license that applies and gives
its text. Where a crate offers a choice of licenses, the entry uses the one named.

scripts/third-party-notices.sh writes this file from the Rust crates linked into the app
and the Sparkle framework the app carries. Do not edit it by hand. Run `make notices` and
commit the result.

## Contents

- libc 0.2.191, under MIT
- tinyvec 1.13.3, under MIT
- unicode-normalization 0.1.26, under MIT and Unicode-3.0
- The Rust standard library, under MIT
- Emoji and symbol data from Unicode, under the Unicode License v3
- Sparkle 2.9.6, under MIT, with the code it carries under its own licenses
